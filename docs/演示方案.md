# 演示方案（约 6–8 分钟）

> 一句话卖点：**它不是"推荐一堆书"，而是"说得清为什么、记得住你、还能排成每天做得到的计划"。**
> 演示的核心不是把功能点一遍，而是让评委在第 3 分钟看到「我反馈一句 → 它记住了 → 下次真变了」。

---

## 一、演示前 5 分钟准备（照着做）

| # | 动作 | 说明 |
|---|------|------|
| 1 | **双击 `scripts\prepare-demo.bat`** | 清空记忆、清缓存，保证从"干净状态"开始（会先备份旧数据） |
| 2 | **双击 `scripts\start-backend.bat`** | 后端跑在 `http://127.0.0.1:8000` |
| 3 | **双击 `scripts\start-frontend.bat`** | 前端跑在 `http://127.0.0.1:5173` |
| 4 | 浏览器打开 `http://127.0.0.1:5173` | 建议全屏、缩放 100%、关掉其他标签页 |
| 5 | 预演一遍剧本 | 确认每一步都符合"预期看到" |

> `.bat` 已经内置了 `-ExecutionPolicy Bypass`，不需要你改系统执行策略；也不要直接双击 `.ps1`（会被签名策略拦）。

**LLM 已接通（DeepSeek）**：密钥在 `~/.config/zhiyu/api_key`，地址和模型在 `backend/.env` 里配好了。后端启动时会读到，推荐说明、记忆压缩、助手问答都会走真实模型。**不需要你再配。**

> 自检：打开 http://127.0.0.1:8000/health 应看到 `llm_model: deepseek-chat`；推荐一次后看「执行轨迹」里 `generate_explanation` 的 `mode` 应是 `llm` 而不是 `fallback`。
>
> 换机器/换密钥时才需要重配：在 `backend/.env` 写 `OPENAI_API_KEY / OPENAI_BASE_URL=https://api.deepseek.com/v1 / OPENAI_MODEL=deepseek-chat`（或把密钥存到 `~/.config/zhiyu/api_key`）。配错了也不会崩：检测不到 Key 会自动回退规则兜底。

## 二、演示剧本（按顺序点）

### 第 1 步｜推荐页：3 秒出一份书单（约 1 分钟）

**操作**：主题选「Python基础」→ 当前水平选「**进阶**」→ 语言「中文」→ 时间拉到「30 分钟」→ 点「生成我的学习路线」。

**预期看到**：5 本书，排序大致是
`流畅的Python(77) / Python Cookbook(77) / 笨办法学Python 3(73) / Python编程：从入门到实践(67) / Python编程快速上手(67)`

**台词**：
> "我没有让它推荐 50 本，而是让它按我的水平、时间和语言，先筛出 5 本并排好序。注意：进阶用户也会拿到入门书——这是设计的渐进难度，而不是硬卡死。"

---

### 第 2 步｜结果页：把"为什么"摊开给人看（约 1.5 分钟）—— 第一次加分点

**操作**：
1. 点任意一本书的「展开评分」→ 看到主题/难度/时间/偏好四个维度的分数条。
2. 右侧切到「**推荐依据**」→ 看路线逻辑（建立核心概念 → 连接真实案例 → 独立应用）。
3. 切到「**执行轨迹**」→ 看到 Agent 的 4 个步骤和耗时。

**台词**：
> "排序不是黑盒：每一项分数怎么来的、路线为什么这么排，都能展开看。右边这条轨迹证明的是——记忆检索发生在搜索之前，打分是确定性规则，**大模型不直接决定排名**。"

---

### 第 3 步｜反馈闭环：让它"记住你"（约 2 分钟）—— **全场最强的点**

**操作**：
1. 在书单里点一本书（比如《流畅的Python》）的反馈按钮 → 选「**难度太高**」→ 保存。
2. 回到结果页，切到「**引用记忆**」→ 看到新出现的记忆：`难度偏好：偏好更简单的书`，并显示来源原文。
3. 点「调整学习条件」→ 不改任何条件，直接再点「生成我的学习路线」。

**预期看到**：排序**明显变化**——更基础的入门书浮到最前：
`笨办法学Python 3(83) / Python编程：从入门到实践(77) / Python编程快速上手(77) / 流畅的Python(67) / Python Cookbook(67)`

**台词**：
> "我只说了一句'太难了'。它把这句话压缩成了一条带置信度的结构化记忆，下一次不用我再说，更基础的书就自动排到了前面。而且我随时能在'记忆中心'看到它记了什么、从哪句话来的。"

> 小技巧：如果想让"页面偏好"变化更明显，可以改成反馈「这本书太厚了」——但注意对「Python基础」这类书大多超过 300 页，系统会自动放宽页数限制（轨迹里会标 `relaxed_pages`），排序变化不如"太难"直观。

---

### 第 4 步｜路线页：从"书单"到"每天做什么"（约 1.5 分钟）

**操作**：
1. 在结果页点 2–3 本书的「加入路线」。
2. 左侧导航进「**我的路线**」。
3. 看「每日阅读安排」：总页数、预计天数、每天拆成 2 本并行、每本读第几页。

**台词**：
> "推荐只是起点。它把书换算成'每天 30 分钟能读多少页'，排成一张能执行的日程，而不是又给你一个收藏夹。"

---

### 第 5 步｜灵犀助手：带着上下文回答（约 1 分钟）

**操作**：点右下角「问问灵犀」→ 输入「怎么安排顺序」或「太难了怎么办」→ 回车。

**预期**：结合当前路线和记忆回答（配了 LLM 时更自然；没配时是规则兜底）。

**台词**：
> "问答也不是一个通用聊天框——它能看到你当前这条路线和你的记忆。"

---

### 第 6 步｜记忆中心收尾（约 30 秒）

**操作**：进「**我的记忆**」→ 点一条记忆看右侧详情（来源原文、置信度、使用次数）→ 展示"可以删除"。

**台词**：
> "最后强调一点：这些记忆是可见、可核对、可删除的。可解释不只是解释推荐，也包括解释'它记住了什么'。"

---

## 三、如果只有 3 分钟（精简版）

只做 3 件事，砍掉其余：

1. **推荐页**：Python基础 / 进阶 / 30 分钟 → 出 5 本。
2. **结果页**：展开一本书的评分 + 切「执行轨迹」看一眼。
3. **反馈闭环**：选一本 →「难度太高」→ 重新推荐 → 指着排序变化说那句"它记住了我"。

---

## 四、常见翻车与应对

| 情况 | 现象 | 应对 |
|------|------|------|
| 没配 LLM Key | "推荐依据"是模板句 | 提前说明"离线时走规则兜底"；评分/记忆/路线不受影响，照样演 |
| 推荐为空 | 页面显示"未找到符合条件的书籍" | 别叠加"英文 + 短书"这类严格条件；用中文 + Python基础最稳 |
| 前端没起来 | 浏览器打不开 5173 | 检查 `scripts\start-frontend.bat` 窗口有没有报错；端口 5173 被占就换端口 |
| 后端没起来 | 页面能开但接口报错 | 看 `scripts\start-backend.bat` 窗口；确认 8000 没被占 |
| 演示中途想重来 | 记忆乱了 | 再双击一次 `scripts\prepare-demo.bat` 即可回到干净状态 |
| 现场网络差 | LLM 慢/超时 | 已配兜底，接口不会卡死；提前把页面打开好 |

## 五、可选加分项（时间够再演）

- **书库检索页**：473 本书支持按主题/难度/语言/页数筛，展示"真实馆藏"的分量。
- **多用户隔离**：切换用户后记忆互不影响，说明"用户隔离"。
- **执行轨迹的细节**：点开某一步看 JSON 参数（`candidates / used / count`），强调"可审计"。
