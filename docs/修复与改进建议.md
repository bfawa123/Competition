# 修复与改进建议

本文件记录了对「灵犀 AI 馆员」代码审查中发现并修复的 bug，以及进一步的改进建议。

## 一、已修复的 Bug

| # | 模块 | 问题 | 修复 | 影响 |
|---|------|------|------|------|
| 1 | `services/recommender.py` | `_score_preference` 用 `m.field == "prefer_cases"` 判断，但规则压缩产出的是 `field="format", value="prefer_cases"`，永远命中不了；`prefer_easier/harder`、`prefer_chinese/english` 也完全没参与评分 | 改为按 `field+value` 匹配 format 偏好；语言偏好读 `field="language"`；难度偏好 `field="difficulty"` 微调目标难度 | **核心功能**：反馈"案例多/太难/喜欢中文"现在会真实改变排序 |

## 二、验证结果

- 项目自带后端测试：**6/6 通过**
- 前端 `tsc` 类型检查：**通过**
- 端到端实测：
  - 首次推荐「Python基础/入门」→ 3 本
  - 反馈"太厚"后 → 仍 3 本（`relax_pages_filter` 生效，原来会 0 本）
  - 进阶用户反馈"太难"后 → 入门书 `笨办法学Python 3` 排到第一（难度偏好生效）
  - 助手接口带 `user_id` 可正常检索记忆

## 三、进一步改进建议（未实施，按优先级）

1. **主题关联覆盖太窄**：`recommender.py` 的 `goal_keywords` 只覆盖计算机类主题，而真实书库有 200+ 主题（外国文学、中国史、西方哲学…）。建议从 `books.json` 自动生成主题共现/相似关系，或接入真正的语义检索（`BAAI/bge-m3`）。
2. **`additional_constraints` 是死字段**：前端有"额外约束"输入框，但后端从未读取。要么接入评分，要么去掉，避免误导用户。
3. **评分权重可学习**：`weight_topic/difficulty/time/preference` 硬编码。可基于用户采纳/拒绝行为做在线调整（bandit / 逻辑回归）。
4. **记忆去重仍粗糙**：按 `field` 覆盖会丢掉同字段的不同取值历史，建议按 `(type, field, value)` 或语义聚合并加入"时间衰减/过期"。
5. **存储可升级**：JSON 文件有写锁但无事务，规模上去建议换 SQLite/Postgres。
6. **接口安全**：`user_id` 由前端直接传、无鉴权/限流，生产环境建议加 token 与限流。
7. **无 LLM 时质量有限**：说明生成和反馈压缩是规则兜底，可补充更丰富的规则或本地小模型。
8. **`embeddings_cache.json` 已是死代码**：`write_memory` 仍写入零向量缓存，但 `retrieve_memory` 已改为现拟合，可删除该缓存逻辑。

## 四、演示准备阶段补充修复

| # | 模块 | 问题 | 修复 |
|---|------|------|------|
| 12 | `utils/secure_config.py` | 读取密钥时会先调用 `op`/`bw` 命令行；在受限环境（沙箱/CI）里 `subprocess` 被拒（`WinError 5`），而异常未被捕获，导致**根本读不到密钥文件**，LLM 永远走兜底 | 把两处 `except` 放宽为 `except Exception`，命令行不可用时直接跳过，继续读密钥文件 |
| 13 | `utils/llm_client.py` | 同上，`_secure_load_key` 抛错会中断整条密钥加载链 | 加 try/except 包裹 |
| 14 | `frontend` 快捷反馈 / `memory_service` | 前端按钮是「**难度太高**」，规则压缩只认「**太难**」，点按钮会生成无用的 `general` 记忆、排序不动 | 规则补上"太高/偏难/看不懂"等；同时去掉会误判的"高阶/入门"关键字 |
| 15 | `utils/scorer.py` + `recommender.py` + `agent.py` | LLM 会把"难度太高"压缩成 `prefer_basic`，而评分器只认 `prefer_easier` → **LLM 开着时记忆反而不生效** | 新增 `normalise_memory_value()` 归一化同义词（basic/easy/简/基础…→prefer_easier），三处比对统一使用；并在 LLM 压缩 prompt 里约束规范值词表 |
| 16 | `services/agent.py` | 轨迹只记 `{action, details, timestamp}`，前端轨迹页要的 `duration_ms / candidates / used / tokens` 全缺，页面指标全是 `--` | 每步记录真实耗时；`retrieve_memory` 带候选/采用数；补 `generate_explanation` 步骤（`mode: llm/fallback` + token 估算） |
| 17 | 依赖 | `openai` 是可选依赖未安装，且新版依赖 `httpx2 → httpcore2 → truststore` | 已安装到 `backend/pylibs`；实测 DeepSeek 调用成功（返回"你好"） |

> 说明：第 12/13 条是**真正的健壮性 bug**——不只是沙箱，任何"没有 op/bw 且子进程受限"的环境（CI、精简容器）都会踩；第 14/15 条会让"记忆改变推荐"这个核心卖点在演示时静默失效。
